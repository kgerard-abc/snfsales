# Budget tables from CEC applications

Made by .github/scripts/cec_budgets.py on November 7, 2026. The numbers are in cec_budgets.csv.

Each application's Appendix A has Table 2 (staff and payroll by job) and Table 3 (revenue and expenses) for three past years (the seller's actual figures), the current year's budget, and the buyer's first three projected years. Applicants label the "Other" expense lines in their own words, so the category column is a best guess from the line's wording; the line column keeps the wording as printed.

A **Check** note means a table did not add up or was not laid out as expected. Look at the page before using those numbers. Homes are matched to the CEC Log by name; "sale never closed" in cec_outcome means the sale did not go through (for example Kadima, 2022), so leave those out of any before-and-after comparison.

Applications read: 71. With tables: 44. Without tables: 26. No copy to read: 1. Homes with numbers: 62. Numbers saved: 14027.
